## 🚀 Быстрый старт

### 1. Настройка движка (`AionTweaker.exe`)
1. Скопируйте `AionTweaker.exe` в корневую папку с клиентом игры (туда, где находится файл `system.cfg`).
2. Запустите утилиту.
3. **Обязательно активируйте первый пункт:**  
   `[✔] Включить боевой лог чата (g_chatlog = 1)` — без этого игра не выгружает данные урона в файл.
4. Выберите желаемые оптимизации (снятие лимита FPS под 144/240 Гц, отключение сглаживания мыши, кэш моделей и предзагрузка шейдеров).
5. Нажмите **«Применить настройки»** (чистый конфиг автоматически сохранится в `system.cfg.bak`).

### 2. Боевой оверлей (`AionDpsMeter.exe`)
> Перед первым запуском оверлея войдите в игру хотя бы один раз, чтобы клиент создал файл `Chat.log`.

* **Запуск из папки игры:** поместите `AionDpsMeter.exe` в корень игры рядом с `system.cfg` — программа найдет лог автоматически.
* **Запуск с Рабочего стола:** при первом запуске укажите путь к `Chat.log` в папке игры через проводник (путь сохранится в конфиг).
* Для корректного отображения окна поверх игры включите в настройках графики режим **«Окно во весь экран»** (Borderless).

## 🛠 Возможности оверлея

* **⚔️ Вкладка DPS:** замер текущего боя (`LIVE`), суммарный урон за всю сессию, детализация скиллов любого игрока по клику на полоску, переключение сортировки `[Урон / DPS]` и свободная прокрутка колесиком мыши.
* **💀 Вкладка PK:** мировая база фрагов на локации, персональные профили игроков с историей убийств и смертей, временные фильтры.
* **📡 Вкладка РАДАР:** пассивное обнаружение врагов в радиусе ~45 метров при активации ими стоек, баффов или ударов. При обнаружении заголовок загорается красным: `📡 РАДАР (X) ⚠️`.
